# HTML & CSS Basics

This repository contains my practice work while learning the fundamentals of **HTML and CSS**.

The goal of this repository was to understand how websites are structured, styled, and displayed in a browser while building a foundation for frontend development.

## What I Learned

### HTML

* Basic HTML document structure
* Headings, paragraphs, and text formatting
* Links and images
* Lists
* Tables
* Forms and input elements
* Semantic HTML
* Buttons and other common HTML elements

### CSS

* Selectors and properties
* Colors, fonts, and text styling
* The Box Model
* Margins and padding
* Borders
* Width and height
* Flexbox basics
* Positioning
* Basic responsive design
* Styling HTML elements

## Technologies Used

* **HTML5**
* **CSS3**
